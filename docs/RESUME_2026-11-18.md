## Where it stands

  `scripts/bootstrap-workspace.sh` (needs access to the private
  `chrissotraidis/ectopad-*` mirrors until release).
- **Reproducible:** fixed 2026-11-18. The linker sometimes took Rust's weak
  compiler helpers (`__udivti3` …) from `libnod_ffi.a` and sometimes
  libSystem's, so a fresh build occasionally differed by 1,008 bytes of code.
  `nod.patch` now strips Rust's `compiler_builtins` members after Corrosion
  copies the library. At commit `2c8b44b`, two fresh workspaces built in
  parallel gave the identical IPA `5b2623c7…` (the build tested on the iPad
  on 2026-11-10) and identical Mac zips `8a1d01f9…`; both pass
  `release_gate.py`, the IPA passes `audit-ios-package.sh`, and the Mac app
  links only system libraries.
- **musyx dropped** (commit `42d42c5` and the follow-up): it is a
  decompilation of the MusyX library used only by its own test. The bootstrap
  no longer fetches it and the license bundle no longer lists it. The app
  binary is unchanged, but the IPA's `Licenses/` folder loses one file, so
  **the final IPA and Mac zip hashes must be rebuilt and recorded** (two fresh
  builds; see "Next steps").
- **Device checks 2026-11-18:** iPad (QuickTime mirror) title screen, warp into
  Chozo Ruins with correct world/HUD, built-in touch/menu self-test passed

  [RELEASE_COMPLIANCE.md](RELEASE_COMPLIANCE.md).

## The open decision (Chris)

The complete source package fails `release_gate.py`: 18 address-named
functions in Metaforce (`sub_8019ebf0` and similar), part of Metaforce's
decompilation-based provenance (it was rewritten with code from PrimeDecomp).
The binaries pass only because names are stripped. Per AGENTS.md this is a
stop until Chris decides, in his release audit, whether to accept that
provenance (the Ship of Harkinian model: code only, players supply their own
game) and mark the repo Clear. Do not rename functions to pass the gate.
