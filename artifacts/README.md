# Binary release status

No EctoPad IPA is currently distributed from this repository.

The previously tracked EctoPad 0.1.3 unsigned IPA and checksum were removed
from the current branch on 2026-08-18. The package was game-data-free and passed
the repository's hygiene audit, but its own bundled documentation correctly
said that public redistribution was not approved.

Generated IPAs and checksums remain ignored. Do not commit, upload, mirror, or
share a locally generated package until every item in
[`docs/RELEASE_COMPLIANCE.md`](../docs/RELEASE_COMPLIANCE.md) is complete.
